# Start here

Open the **[[Dashboard.base|Dashboard]]** for your to-do views. New to Obsidian? See the **[[Glossary]]**.

## Reading the graph
🟡 **Paths** · 🔵 **Topics** · 🟣 **Tools** · 🟢 **reels rated 3/3** · ⚪ other reels.
The graph hides the collection hubs, this note, and reels rated 1/3. Click any node and open its **local graph** (right sidebar) to see only its neighbors.

## How notes are organized
- **Reels/**: one note per saved reel: what it shows, how it applies to you, links, setup steps and caveats. The caption and transcript are folded at the bottom.
- **Topics/**: a fixed topic list (from `config.yaml`). A new topic gets added only when 3+ reels need it.
- **Tools/**: one note per tool that shows up in 2+ reels, with its real install command and an honest read on the hype.
- **Collections/**: one note per Instagram collection (hidden from the graph).
- **Paths/**: ordered plans you build from the reels.

## Fields you edit
| Field | Values | Meaning |
|---|---|---|
| `status` | `inbox` · `try` · `tried` · `skip` | Every reel starts at `inbox`. `skip` hides it from the dashboard. |
| `relevance` | 1–3 | How much it applies to you right now (set by Claude; change it freely). |
| `effort` | `5 min` · `1 hour` · `weekend` · `ongoing` | Rough time to act on it. |
